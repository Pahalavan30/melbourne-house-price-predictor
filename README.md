# Melbourne House Price Predictor

A machine learning model that predicts Melbourne house sale prices from property features, served through a FastAPI endpoint in Docker.

> Work in progress - building this over the next few days.

## Data
Melbourne Housing Snapshot: 13,580 sales from 2016-2017 (Suburb, Rooms, Type, Distance to CBD, Land size, and more).

## Plan
1. Exploratory data analysis - `notebooks/01_eda.ipynb`
2. Baseline + models (linear regression, XGBoost)
3. FastAPI + Docker
4. Deploy on AWS
